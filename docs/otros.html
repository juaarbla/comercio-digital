CartoBlocks for Leaflet: cuando el mapa deja de ser un shortcode

En el ámbito de WordPress, ha salido un nuevo plugin que simplifica la creación de mapas interactivos, un elemento clave para cualquier web de comercio. La novedad más importante es que permite integrar estos mapas directamente en el editor sin necesidad de utilizar códigos especiales o shortcodes. Esto refuerza la tendencia del diseño web moderno: hacer que funcionalidades complejas sean accesibles mediante la estructura de bloques (Block Editor). Para nosotros, como profesionales, esto significa que podemos montar secciones avanzadas de forma intuitiva, mejorando la usabilidad de los sitios sin requerir conocimientos de programación.
